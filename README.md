# IOSHUBv2

Unofficial, fan-made statistics platform for [IOSoccer](https://iosoccer.com).
Live at **[ioshubv2.com](https://ioshubv2.com)**.

> This project is not affiliated with, endorsed by, or officially connected to
> IOSoccer in any way. All game data belongs to IOSoccer and its community.

---

## Features

### Matches
- Full match archive with pagination
- Filters by type (competitive / friendly) and region (EU / AM)
- Live match tracker for in-progress games
- Per-match detail pages: lineups, player stats, Player of the Match,
  events timeline, head-to-head history, server location

### Players
- Searchable player directory with minimum-appearances filter
- Leaderboards across multiple metrics
- Player profile tabs: matches, statistics, team history, tournaments, POTM
- Head-to-head comparison between any two players
- Transfer history

### Teams
- Active teams grid
- Team profile tabs: squad, results, tournaments, lineups, player history,
  statistics
- Team vs team head-to-head

### Tournaments
- Active and past tournaments
- Filters by type (Club / National / Mix / Draft) and format
- Tournament detail pages with standings and fixtures

### Ratings
- Monthly player-rating leaderboard
- Historical rating distribution chart
- Configurable minimum-matches threshold

### Misc
- Global player + team search
- Fixtures overview
- Dark / light theme
- Ko-fi support button

---

## Data source

All data is fetched from the [IOSoccer public API](https://iosoccer.com) in
real time. Nothing is independently collected, altered, or permanently stored
beyond temporary caching for performance. IOSHUBv2 claims no ownership of any
IOSoccer data.

For feedback or bug reports, use the Support page on the live site.
